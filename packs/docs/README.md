# Docs office pack

Keep developer docs, user guides and change explanations in line with the code, and keep them short.

The pack adds one office with 2 members of its own and uses 3 core team agents by reference (nothing is copied twice). Give the lead (`docs-lead`) a goal in plain words.

## Members

| Id | Title | What they do |
| --- | --- | --- |
| `docs-lead` | Docs Lead | Leads the docs office: finds which docs a change made wrong and assigns the update by name |
| `readme-trimmer` | README Trimmer | Shortens a README to what a new reader needs, and lists what it removed |
| `dev-docs` | Dev Docs | Core team agent, used by reference |
| `user-guide` | User Guide | Core team agent, used by reference |
| `docs-explainer` | Docs Explainer | Core team agent, used by reference |

## Sample tasks

1. **Trim an invented README** (for `readme-trimmer`): Shorten the invented README I name to install, run, test and purpose, and list what you removed.
2. **Find the docs a change made wrong** (for `docs-lead`): From the invented change summary I name, list every doc sentence that is now wrong and who should update it.

## Limits

- Members prepare drafts and reports. They never send, post, pay or publish; Arsenale asks before any such step.
- A pack can only make the rules stricter.
